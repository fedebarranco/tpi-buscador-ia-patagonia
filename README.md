# Buscador con IA para Patagonia Argentina

Trabajo Práctico Integrador (TPI) de **Organización Empresarial** — Tecnicatura Universitaria en Programación a Distancia (TUPaD), UTN. 2026.

## Descripción del sistema

Patagonia Argentina (patagonia-ar.com) vende por una tienda hecha en Shopify. El proyecto consiste en mejorar el **buscador del sitio** para que entienda búsquedas escritas como habla la gente (por ejemplo, "algo para la cabeza" muestra gorros, gorras y pañuelos), pasando de la versión actual de la app Boost a su versión Turbo con funciones de IA.

Este repositorio aloja la documentación del proyecto: el proceso modelado en BPMN, las historias de usuario y los indicadores de control.
